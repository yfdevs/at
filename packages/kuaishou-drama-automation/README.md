# Kuaishou Drama Automation

快手短剧自动化运行时包。

当前已实现：

- 快手经营者平台登录态复用和基础表单填写。
- 接入 `/dramaAiRpa/kuaishou` 后端接口：读取启用账号、查询 READY 任务、领取任务，并回写成功或失败结果。
- 每个启用账号使用独立浏览器登录态并持续轮询任务，轮询间隔由桌面端配置控制。
- 一个任务按顺序生成“全剧付费”和“观看广告解锁”版本。
- 配置全局 AI 后，发布前分析原封面中的剧名/干扰文字和核心主体，并通过 Sharp 生成
  3:4、900×1200 的广告解锁版封面；未配置 AI 时，广告解锁版沿用原封面和原有裁剪上传流程。
  全剧付费版始终使用原封面。AI 结果按原图、模型和提示词版本缓存，AI 分析或裁剪校验失败时不会进入平台提交阶段。
- 两个版本都完成上传并提交审核后才回写任务成功；任一版本失败都会按失败阶段回写错误。
- 任务可提供 `baiduPanResourceLink` 百度网盘分享文本。开始填写表单前会先下载到
  `localEpisodeVideoRoot/originalTitle`，并严格校验第 1 集至任务总集数是否完整、是否存在重复集数，
  同时从文件名或目录名包含“封面”或“海报”的图片中自动匹配短剧封面和单集封面；快手海报图片无需上传。
- 导演和编剧姓名固定使用“米苏”，制片人姓名使用制作机构名称，性别均默认选择“男”。
- 主要演员无需任务配置，固定生成两人：姓名均为“米苏”，分别为“男/主角”和“女/配角”。
- 授权推广材料和短剧制作协议/权属声明固定使用包内 `src/assets/授权推广.jpg` 和
  `src/assets/短剧制作协议.jpg`，所有任务共用，不读取后台版权文件字段。
- 百度网盘下载失败按 `baiduNetdiskDownloadRetryAttempts` 重试；链接无效、登录过期、剧集目录不存在、
  集数重复或缺集属于不可重试的数据错误，会直接上报任务失败。
- 批量视频上传完成轮询由 `videoUploadTimeoutMinutes` 控制，默认 120 分钟。
- 根据任务总集数创建单集信息槽，并通过“批量设置”统一单集标题、封面和价格范围。
- 全剧付费：第 1～7 集免费，第 8 集到最后付费；不足 8 集时全部免费。
- 广告解锁：第 1 集免费，第 2 集到最后按页面“付费”状态设置，由“观看广告解锁”售卖方式决定实际解锁行为。

完成剧集设置后会点击“下一步”和确认提示，并等待页面地址进入 `step=1` 视频上传步骤。

## 广告封面预览测试

使用桌面端全局 AI 配置对一张本地海报执行真实分析和裁剪：

```bash
pnpm kuaishou-drama:preview-ad-cover -- "D:\path\poster.jpg"
```

输出位于原图同目录的 `AI裁剪预览`。需要仅调整裁剪算法、复用上次模型坐标时可追加
`--reuse-analysis`，避免重复调用模型。
