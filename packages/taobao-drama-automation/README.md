# 淘宝短剧批量上传自动化

淘宝平台由用户选择 Excel 导入本地 SQLite 任务库。自动化运行时只从数据库领取任务，不读取 Excel、账号后台或任务后台接口，也不创建合集、不填写剧目资料。

## Excel 格式

工作簿可包含多个工作表，每个有效工作表必须包含以下列：

- `剧名`
- `网盘链接`（百度网盘分享链接）
- `集数`（1-100 的整数）

系统会跳过完全空白行，校验后把有效行写入本地数据库并报告错误行。相同剧名、网盘链接和集数的任务不会重复入库。

## 执行流程

1. 从 Electron 本地 SQLite 数据库领取待上传任务。
2. 按剧名和百度网盘链接下载视频素材，并可选读取资源中的 TXT、MD、DOCX 简介文件；没有简介时继续执行。
3. 使用全局 AI 配置一次生成一个题材标签和全部分集概括，并缓存到本地 SQLite，失败重试时直接复用。
4. 校验本地视频数量与 Excel 集数一致。
5. 打开淘宝批量发布页并批量选择视频，单次最多选择 100 集。
6. 逐集填写 `第N集|约10字概括`；三个内容标签分别通过“内容标签 → 搜索 → 点击精确匹配项”添加为淘宝结构化标签，而不是直接输入普通文本；创作者声明明确选择并校验“含AI生成内容”；在“选择其他合集”的下拉列表中滚动并精确选择与剧名同名的合集。
7. 等待全部视频上传完成，点击批量发布并完成成功校验与至少 10 秒结算期。
